# espOS logo

The mark used for the signalk-espOS GitHub organisation and npm scope: the
espOS chip (the signalk-espos-manager app icon) as the message in a
bottle on a wave.

The bottle and wave are a nod to the Signal K logo in its blue (`#003399`)
and yellow (`#FBCA02`), drawn from scratch rather than copied from the
Signal K artwork, which belongs to the Signal K project.

| File | Use |
|------|-----|
| `espos-logo.svg` | Source; scale it for anything else |
| `espos-logo-1024.png` | GitHub organisation avatar |
| `espos-logo-512.png` | npm / Gravatar avatar |
| `espos-logo-64.png`, `espos-logo-32.png` | Favicons and small badges |

The design keeps everything inside the inscribed circle, so it survives the
round crop GitHub and npm apply to avatars.
